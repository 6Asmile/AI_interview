# 项目变更日志

## 2026-08-12｜可靠异步底座、统一模型网关与运行验证

### 代码与数据范围

- 代码验证提交：`89313f8268e96d79b6968b39846f319c0892f50c`（`feat: 完善可靠异步底座与项目验证能力`）。
- `core.AsyncOperation` 原表就地演进为平台权威 Operation，补齐输入/结果引用、幂等哈希、attempt、lease、heartbeat、fencing、状态版本、取消、trace/correlation、耐久事件游标与终态约束；新增 `OperationDispatchOutbox` 和 append-only `OperationEvent`，并给 `ConsumerInbox` 增加 claim/lease/fence。
- 高成本 Resume、Career、Knowledge、Media、Community 入口在同一 PostgreSQL 事务创建领域快照、Operation 与 Dispatch；Worker 只接收 `operation_id`，通过处理器白名单从数据库重载输入。Agent 保留专用 Execution/Checkpoint/Dispatch 状态机，补显式 lease/fence，并对外一对一投影统一 Operation。
- 新增 Core 迁移 `0004_authoritative_async_operations` 以及各领域 Operation 关联/输入快照迁移；只扩展和回填，不破坏旧表、旧 UUID 或运行中旧任务。
- 统一 v2 Operation detail/events/retry/cancel 契约；同一 Idempotency-Key 的响应 Header、Body 与 URL 复用同一个 Operation UUID，跨用户查询返回 404。

### Redis、RabbitMQ 与模型执行

- 新增唯一 Redis Key Builder、敏感标识 HMAC、Lua 多维原子令牌桶、owner-check lease、验证码 generation、一次性 WebSocket Ticket；开发/预发布 Compose 拆为 Cache、Coordination、Realtime 三个进程，并定义各自 fail-open/fail-closed/快照恢复行为。
- RabbitMQ 保留稳定 exchange，队列迁移到 `ifaceoff.v2.*`；关键域使用 Quorum Queue 与按域 DLQ，Publisher/Recovery 与业务 Worker 分离，Document/Media 和 Publisher/Notification 不再共用 Worker。
- 删除“声明但没有真实消费链”的 TTL Retry Queue 口径。业务重试以 `OperationDispatchOutbox.available_at` 为唯一时钟；Broker 只负责运输、Worker 崩溃 redelivery 与 delivery limit 后 DLQ。
- 管理端 Operations/Reliability 明确区分 PostgreSQL Outbox Dead 与 RabbitMQ Broker DLQ。Broker DLQ 的真实读取、dry-run/replay、原路由校验和失败不 ACK 仍为 `partial/pending-verification`。
- Chat、Embedding、Rerank、ASR 与 TTS 已统一进入 Model Gateway 的 Request/Attempt 账本、共享 deadline、错误分类、连接池、流式首 Token 锁定与 Redis Closed/Open/Half-open 熔断；业务模块不再直接创建 OpenAI 客户端。

### 管理端、可观测性与安全

- Candidate Task Center 与 Staff Operations/Reliability 页面接入 Operation 状态、耐久事件、retry/cancel、Redis capability、队列水位、stale lease 与降级原因。
- 新增内部 `/internal/metrics` 与 Prometheus/Grafana 开发配置；指标覆盖 Operation、Dispatch/Outbox、Inbox、准入、Redis、Rabbit、Celery、Gateway/RAG，禁止用户、租户、Operation UUID 或正文等高基数字段。
- Staff 管理写使用数据库先 claim 的幂等协议；安全流程和高成本任务在 Coordination Redis 不可用时 fail-closed，普通读取继续。
